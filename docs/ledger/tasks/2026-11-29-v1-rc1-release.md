## Risks and open questions

- **`PipelineError::AdapterBuild(Vec<AdapterBuildFailure>)`**: the payload's
  type is defined in `runtime::factory` (crate-private) and re-exported only
  `#[doc(hidden)]` at `runtime::`, and is not `#[non_exhaustive]`. So a frozen
  variant carries a type outside semver. Options for the owner: make it
  canonical public (`#[non_exhaustive]`, in `pipeline` or `runtime`) before
  1.0, or leave it (fields readable, type unnameable within semver).
