# Release 0.12.1

## Objective

Ship 0.12.1, the security release for GHSA-6chh-gx4c-448g (path traversal and
file-name collisions in the file-backed stores) and GHSA-x8vc-9h5c-gh55
(credentials in adapter configuration errors). It also carries the DLQ data-loss
fixes and the dependency updates. Then remove the version drift between the
release, the crates, the binary and the README (F-07), and check on every tag that
they agree.

## Acceptance criteria

- [x] Both advisories published by the owner; main contains the fix.
- [x] Upstream CI green on main for the merge commit before tagging (owner,
  2026-11-25: the fix had never run in Actions, the Unix 0600 test included).
- [x] Annotated tag `v0.12.1`; the release workflow builds every binary; a GitHub
  release with the notes, linking both advisories.
- [x] The v0.9.0 release says "Affected by GHSA-6chh-gx4c-448g. Upgrade to 0.12.1."
  at the top. v0.11.0 and v0.12.0 are not tagged.
- [x] F-07: the latest release, every crate's version, `kulyrax --version` and the
  README agree on 0.12.1, and the README's install links point at the latest
  release.
- [x] On a tag push, CI checks that the tag equals the workspace version (already
  in `release.yml`) and the binary's `--version` (added here).
