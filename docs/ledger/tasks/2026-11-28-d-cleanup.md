  enum). It is built only by `events_from_path` and iterated, as before. No
  code outside `replay.rs` used the variants, so no accessors are needed.
- [x] `RuntimeError` and `runtime::error` are removed. The D6 error test no
  longer names it, and CONTRIBUTING's pattern example points at
  `source::SourceError`. The 0.12.0 API snapshot (`docs/stability/api/`) is
  history and unchanged.

    and `io_err` turns it into the typed variant. Its message is unchanged.
  - It marks `PrepareFailure::refused`, and stays a refusal in a rebuild.
  - CLI test in `exit_4_when_a_safety_check_refuses`.
- [x] Decision 2026-11-26-exit-codes: the follow-up is marked resolved,
  quoting the owner; its "Revisit if" items are done.
- [x] Docs:

  - rc.1 notes ("One path per type": `EventsFromPath`, `RuntimeError`;
    "Exit codes": the file-store lock).
- [x] Gates: fmt, clippy `-D warnings` (also `unstable-pb`), rustdoc
  `-D warnings`, workspace tests, examples, every Docker backend suite.
- [ ] PR merged with every required check green.
