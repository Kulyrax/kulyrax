# Kulyrax v0.5.0-alpha

## Status
Alpha — architectural stabilization release.

This release marks the completion of the core engine split and the introduction of the first public API surface.

---

## Highlights

### Core / CLI Split
- `kulyrax-core` contains the full event projection engine
- `kulyrax-cli` is a thin orchestration layer
- No engine logic remains in the CLI

### Public API (First Cut)
- Introduced `execute_event(...)` as the official library entry point
- API is synchronous and deterministic
- No retries, no rollback, no async guarantees

### Idempotency (Locked)
- SQL adapter enforces event-level idempotency
- Document adapter enforces filesystem-level idempotency
- Replay is safe and explicit

### Test Architecture
- Routing tests (config-backed)
- Dispatch tests (behavioral)
- Adapter-level idempotency tests
- Public API smoke test

---

## Non-Goals (Explicit)
- No configuration DSL yet
- No plugin system
- No async runtime
- No service/daemon mode
- No backward compatibility guarantees

---

## Intended Audience
- Core contributors
- Early technical reviewers
- Architecture validation

Not intended for production use.
